Kai 1.7.2 – Cardex-Import

Cardex hängt an seine öffentlichen JSON-Exportlinks einen zusätzlichen Parameter für die Tags. Kai akzeptiert das aktuelle Linkformat und gibt den Wert beim Download unverändert weiter. Ältere Links ohne den Parameter funktionieren ebenfalls.

Diego und drei weitere Karten lieferten beim Abruf ihrer öffentlichen Exporte eine Charakterdefinition und eine Begrüßung. Die automatisierte Prüfung deckt den Import über das aktuelle Linkformat sowie das bisherige Format ab.
