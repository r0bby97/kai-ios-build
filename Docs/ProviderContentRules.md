# Kai – Inhaltsregeln der KI-Anbieter

Geprüft am 8. November 2026. Dies ist eine Einordnung der veröffentlichten Regeln, keine Zusage, dass ein Modell eine bestimmte Szene ausgibt. Eine 18+-Markierung einer Charakterkarte ist keine Freigabe durch den KI-Betreiber. API-Abrechnung und Verbraucher-Abos sind ebenfalls getrennt.
